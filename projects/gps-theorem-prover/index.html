O que é

O projeto explora busca de provas no estilo meios-fins para lógica proposicional e adiciona uma camada educacional para teoremas de análise real, como limites, continuidade e derivadas simbólicas.

Destaques

  • Expressões simbólicas imutáveis para lógica proposicional.
  • Busca recursiva de provas com regras como Modus Ponens e De Morgan.
  • Geração de passos legíveis, não apenas verdadeiro ou falso.
  • Suporte a expressões reais simbólicas com somas, produtos, quocientes e potências.
  • Provas educacionais para limites, continuidade e derivadas.
  • Suíte de testes sem dependências externas usando unittest.
