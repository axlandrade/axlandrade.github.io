O que é

O Math AI Tutor é uma aplicação educacional pensada para conduzir conversas de estudo com explicações passo a passo, formatação matemática adequada e adaptação do prompt ao assunto da pergunta.

Destaques

  • Interface web simples e responsiva construída com Streamlit.
  • Integração com a API da OpenAI para gerar respostas pedagógicas.
  • Detecção heurística de tema para Matemática, Física ou perguntas gerais.
  • Memória curta configurável para preservar contexto recente da conversa.
  • CLI para testes rápidos e uso local no terminal.
  • Logs em JSONL para auditoria, depuração e evolução do tutor.
